# TimeTravel Agency

Webapp immersive et responsive pour une agence fictive de voyage temporel premium.

## Description

TimeTravel Agency présente trois destinations temporelles, un agent IA simulé, un quiz de recommandation, une personnalisation de voyage et un formulaire de réservation sans backend obligatoire.

## Technologies utilisées

- HTML, CSS et JavaScript local pour une version directement ouvrable
- Structure inspirée React avec données locales et composants logiques côté script
- Design type Tailwind CSS : utilitaire, responsive, glassmorphism, gradients et animations
- Framer Motion non requis pour cette version autonome

## Fonctionnalités implémentées

- Header fixe avec navigation et CTA
- Hero immersif avec vidéo locale si disponible et fallback animé
- Présentation de l’agence
- Galerie interactive des destinations : Paris 1889, Crétacé, Florence 1504
- Section détail dynamique par destination
- Timeline de l’expérience client
- Agent IA simulé intégré et chatbot flottant
- Quiz de recommandation personnalisée
- Formulaire de réservation avec confirmation personnalisée
- FAQ automatisée en accordéon
- Footer avec mention pédagogique
- Responsive mobile, tablette et desktop

## Outils IA utilisés

- Codex pour la génération de la webapp, la structure, le contenu et les interactions
- Chatbot simulé local par mots-clés, sans appel API

## Instructions d’installation

Aucune installation obligatoire pour la version livrée. Ouvrir simplement :

`outputs/index.html`

## Instructions de déploiement

Déployer le fichier `index.html` sur n’importe quel hébergement statique. Les vidéos locales référencées depuis `Downloads` peuvent être copiées dans le dossier du projet et les chemins vidéo adaptés si nécessaire.
